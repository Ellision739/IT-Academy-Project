# IT-Academy-Project
# Система управления личной библиотекой

Веб-приложение для автоматизации процессов личной или корпоративной библиотеки, разработанное в рамках финального проекта. Система позволяет пользователям искать книги, управлять бронированием, а администраторам — контролировать выдачу экземпляров.

## Основной функционал

* **Авторизация и профили:** Регистрация новых читателей, кастомные профили пользователей (с сохранением контактных данных и адреса).
* **Каталог и умный поиск:** Поиск книг по авторам, жанрам и названиям с динамическим отображением количества доступных экземпляров.
* **Онлайн-заказ:** Возможность забронировать конкретный экземпляр книги онлайн с автоматическим изменением статуса доступности и защитой от дублирования заказов.
* **Кабинет читателя:** Просмотр текущих бронирований и истории выдачи книг в личном кабинете.
* **Админ-панель:** Полноценный интерфейс для библиотекаря, позволяющий изменять статусы экземпляров (Доступно, Забронировано, На руках, Архив).

## Стек технологий

* **Backend:** Python 3.x, Django Framework
* **Frontend:** HTML5, CSS3, Bootstrap 5 (адаптивная верстка)
* **Database:** SQLite (локальная база данных для разработки)
* **Качество кода:** Flake8 (проверка на соответствие стандарту PEP8)
* **Тестирование:** Django TestCase (Unittest)

## Инструкция по развертыванию и запуску

### 1. Клонирование репозитория и переход в папку проекта
```bash
git clone <ссылка_на_ваш_репозиторий>
cd IT-Academy-Project
```
## 2. Настройка виртуального окружения

```bash
# Создание окружения
python -m venv .venv

# Активация (Windows)
.venv\Scripts\activate

# Активация (Linux/macOS)
source .venv/bin/activate
```

## 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

## 4. Применение миграций базы данных

```bash
python manage.py migrate
```

## 5. Запуск локального сервера разработки

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу: `http://127.0.0.1:8000/`


## 6. Загрузка демонстрационных данных

В проекте подготовлен полный логический бэкап базы данных (включая аккаунт администратора, профили читателей и заполненный каталог книг). Чтобы развернуть эти данные на вашей локальной машине, выполните команду в терминале:

```bash
python -X utf8 manage.py loaddata db_backup.json
```
